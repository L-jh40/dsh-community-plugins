社区插件索引随 dsh-web 家族对齐到统一版本 0.4.14。本版本收录两条社区插件条目，索引条目总数从 148 增至 150；索引数据源、包名、安装方式与宿主版本门槛均保持不变。

> **兼容性**：本版本没有破坏性变更。冻结标识全部保持原样——包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（仍按同一包名从 registry 安装，包内 `files` 清单与 `exports` 入口不变）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。宿主下限保持 `dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 的 `>=0.2.1-rc.3`，既未收紧也未放宽，停在 rc.3 及以上的宿主都能直接安装。

### 新功能

- 收录架构设计与代码的建模审查 `dsh-model-everything`：Mermaid / PlantUML 源码直接画成架构图——分层布局、父子分组、结构预算、两版设计之间的包含关系比对、右栏白板；还能读取并审查 UML 图，把状态机与协议当作模型来判定，检查数据模型与迁移的覆盖与回滚对称性，用有限词自动机判定语言等价与包含并给出最短反例，挖掘并发声称后分派给能判定它的工具，审查依赖图并对比报告。它取代同作者的 `dsh-logicprobe`：新工作从这里开始，旧插件只为既有安装保留。版本以 `npm` 字段为准，尚无社区使用数据
- 收录便捷输入框 `dsh-composer-ease`：给 DSH Web 输入框加补全与编辑——括号与引号自动配对、选中一段再打符号直接框住、跳过闭符、空对一次删两侧；补全弹层给本文词、语言词表、工作区文件与模型名，中文候选来自词典（含领域词表、无写死长度上限），打满两个字符自动弹出、Tab 接受、回车保持发送。中文输入法打出的全角括号默认换成半角 `()`，菜单可关回全角。标准 DSH bundle 插件：一条命令安装、零第三方运行时、不写文件、不改宿主源码；语言词表在服务端，改过需重启 `dsh web`

The community plugin index publishes on the family's aligned version 0.4.14. This release registers two community plugin entries, growing the index from 148 to 150 entries; the data source, the package name, the install path and the host version floor are unchanged.

> **Compatibility**: there are no breaking changes in this release. Every frozen identifier is unchanged: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry, with the same `files` list and the same `exports` entry points); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. The host floor stays at `>=0.2.1-rc.3` in `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer: it is neither tightened nor relaxed, so any host on rc.3 or later installs this release directly.

### New Features

- Register Architecture Design & Code Modeling Review `dsh-model-everything`: a Mermaid or PlantUML source drawn as an architecture diagram - layered layout, nested packages, structure budgets, a containment diff between two designs, and a sidebar whiteboard; UML diagrams are read and reviewed, state machines and protocols are decided as models, data models and migrations are checked for coverage and rollback symmetry, finite-word automata decide language equivalence and inclusion with the shortest witness, concurrency claims are mined and routed to the checker that can decide them, and dependency graphs are audited with reports diffed. It supersedes the same author's `dsh-logicprobe`: start new work here, and the older plugin stays only for existing installs. The `npm` field carries the version; no community usage data yet
- Register Composer Ease `dsh-composer-ease`: adds completion and editing to the DSH Web composer - bracket and quote pairing, wrap-on-selection, closer skipping, and empty-pair backspace; the completion popup offers draft words, language tables, workspace files and model ids, with Chinese candidates taken from a dictionary (domain wordlists included, no hardcoded length cap), opening after two characters, accepted with Tab, and Enter still sends. Full-width brackets typed through a Chinese IME become half-width `()` by default, and a menu switches that back. A standard DSH bundle plugin: one command to install, no third-party runtime, writes no files, and does not modify host sources; the language tables live on the server, so a change to them needs a `dsh web` restart
