社区插件索引随 dsh-web 家族对齐到统一版本 0.4.15。本版本收录一条社区插件条目，索引条目总数从 150 增至 151；同时把宿主版本门槛从 `>=0.2.1-rc.3` 抬升到 `>=0.2.2-rc.1`。包名、索引数据结构、安装方式与线协议均保持不变。

> **兼容性**：本版本没有破坏性变更，但有一条需要留意的安装门槛变化——`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 从 `>=0.2.1-rc.3` 抬升到 `>=0.2.2-rc.1`，低于 rc.1 的宿主不再满足声明，需要先把宿主升到 0.2.2-rc.1 或更高再安装本版。其余冻结标识全部保持原样——包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（仍按同一包名从 registry 安装，包内 `files` 清单与 `exports` 入口不变）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。索引条目结构不增删字段，既有 150 条条目的文本与字段均未被改写。

### 新功能

- 收录组件看板 `dsh-widget-board`：侧栏「看板」入口打开一页可拖拽、可缩放的多标签卡片看板，首次打开自带默认看板，设置页支持看板重命名、移除与切换。每个组件由 `widget.json`、`index.html`、`style.css`（及可选 `main.js`）组成，运行在严格 CSP、无网络与 Cookie 的独立沙箱 iframe 中，只经 MessagePort 桥通信；权限授权绑定组件内容哈希，凭据由宿主凭据服务保管且对组件代码不可读。组件来源覆盖内置、用户自写、Agent 生成与第三方插件（经 `widgetBoard` 服务注册组件、数据源、动作与宿主能力）；插件向会话注册 7 个 `widget_*` 工具与 `widget-authoring` 技能，可用 `widget_show` 在回复里内联渲染卡片。条目的 `npm` 字段只写包名，商店按最新发布版本解析

### 修复

The community plugin index publishes on the family's aligned version 0.4.15. This release registers one community plugin entry, growing the index from 150 to 151 entries, and raises the host version floor from `>=0.2.1-rc.3` to `>=0.2.2-rc.1`. The package name, the index data structure, the install path and the wire protocol are unchanged.

> **Compatibility**: there are no breaking changes in this release, but one install-floor change needs attention: `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer move from `>=0.2.1-rc.3` to `>=0.2.2-rc.1`, so a host below rc.1 no longer satisfies the declaration and must be upgraded to 0.2.2-rc.1 or later before this release is installed. Every other frozen identifier is unchanged: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry, with the same `files` list and the same `exports` entry points); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. The entry shape gains and loses no fields, and none of the existing 150 entries has its text or fields rewritten.

### New Features

- Register Widget Board `dsh-widget-board`: a sidebar Board entry opens a multi-tab page of draggable, resizable widget cards, pre-populated on first launch, with board rename, removal and switching in Settings. Each widget consists of `widget.json`, `index.html` and `style.css` (plus an optional `main.js`) and runs inside an isolated sandboxed iframe under strict CSP with no network or cookies, talking only through a MessagePort bridge; permission grants are bound to the widget content hash, and credentials are held by the host credential service and are unreadable to widget code. Widget sources cover built-in, user-written and agent-authored components as well as third-party plugins, which register widgets, data sources, actions and host capabilities through the `widgetBoard` service; the plugin also registers seven `widget_*` session tools and the `widget-authoring` skill, and `widget_show` renders a card inline in a reply. The entry's `npm` field carries the package name only, so the store resolves the latest published version

### Fixes

- None: no commit in this range corrects existing behaviour, and the only content commit appends one new entry at the tail of the index

- The host floor moves twice: within the range it first follows the 0.2.2-alpha.3 cohort to `^0.2.2-alpha.3` SDK devDependencies and Cordis `^4.0.6-alpha.2`, then follows the 0.2.2-rc.1 cohort to `^0.2.2-rc.1` and Cordis `^4.1.0`; `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer settle at `>=0.2.2-rc.1`. Both cohort moves update the lockfile, the release-age exclusion ledger (318 entries to 342), the bilingual README badges and the pairing hashes
