社区插件索引随 dsh-web 家族对齐到统一版本 0.4.16。本版本是自 v0.4.15 以来改动最大的一轮：索引新增 6 条条目、按宿主下限口径退役 52 条既有条目、并重新登记 1 条，目录规模从 151 条降到 106 条。包名、索引数据结构、安装方式与线协议均保持不变。

> **兼容性**：本版本没有破坏性变更——`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 维持 `>=0.2.2-rc.1` 不变，本轮 `package.json` 除 `version` 外没有任何改动。其余冻结标识全部保持原样——包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（仍按同一包名从 registry 安装，包内 `files` 清单与 `exports` 入口不变）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。索引条目结构不增删字段。唯一需要留意的是目录规模从 151 条降到 106 条：退役只作用于商店目录，本仓只保存链接与元数据、从不托管插件代码，因此条目被移除不会触及任何已安装的插件包。

### 新功能

- 收录组件通知插件 `dsh-plugin-desktop-notify`：一轮结束、等待审批／回答／计划确认以及本轮出错时各弹一条桌面横幅，应用图标上以未读角标显示需要处理的会话数，点横幅切到对应会话；文案跟随 DSH 界面语言，子智能体会话默认不提醒，标题与正文长度可配置，宿主另在回环地址上开放一个 HTTP 接口供脚本与其它工具发通知
- 收录插件自动更新 `dsh-plugin-auto-update`：按包白名单到 npm 查询已装插件的最新版本，只更新勾选的包，本地 link 与 file 安装、锁定版本和出错的包一律跳过，默认不跨大版本、不装预发布；更新走 profile 里运行中的官方插件管理器，profile 写锁、pnpm 执行、bundle 补丁校验与热重载都由宿主负责，安装失败会把旧版本装回去，每轮结果追加到一份 JSON 日志
- 收录学习陪练 `dsh-tutorloop`：围绕自选资料做小步练习、证据反馈与 Leitner 间隔复习，18 个教师工具配中英双语学生面板，复用当前 DSH 会话模型而无需另配模型密钥；学习记录按工作区保存在本地，选用资料与作答可发送给宿主模型，内置 6 道自编示例题、真题库需自行导入。条目声明需 DSH `>=0.2.1-rc.2 <0.3.0-0` 与 Python 3.11+
- 收录 `dsh-character-cards`：为每个会话绑定可切换的角色卡，身份、语气、代码风格与硬性约束按会话注入，支持默认卡、单会话覆盖、可视化编辑器与单文件导入导出
- 收录桌面版电源菜单 `dsh-power-menu-mac`：右上角电源按钮提供关闭 DSH 与重启 DSH，重启会把窗口拉回来并确认新进程真的注册到窗口服务器；接口注册在宿主自带 web 服务器的本机回环地址上，启用后向会话注入一段说明这些按钮用法的全局提示，仅支持 macOS
- 收录联网搜索 `dsh-keenable`：把宿主内置的 `web_search` 与 `web_fetch` 接到 Keenable，不新增工具，任何模型（含本地模型）都能联网；`web_search` 返回排序结果、页面摘录与已知发布日期，`web_fetch` 在服务端抓取并返回 markdown 且不抓 localhost 与内网地址。安装时把宿主的 `searchProvider` 与 `fetchProvider` 固定为 keenable，卸载后恢复宿主默认值；免 key 调用按出口 IP 限 10 次每秒、1000 次每小时，可用环境变量 `KEENABLE_API_KEY` 解除限制，搜索词与抓取 URL 会发送给 Keenable
- 重新登记 `dsh-llm-verifier`：该条目在本次退役中随其它条目一并移除，随后上游 0.19.0 把 `engines.dsh` 与全部 8 条 DSH peer 收窄为 `>=0.2.0-rc.1 <0.3.0-0`，registry 的 latest 与 0.19.0 元数据均已回读该范围，于是按正常登记录径重新追加到数组末尾，未为它开设规则例外；四个工具、自动验收与 Web 设置页的描述已对照上游当前 manifest、测试与源码复核

The community plugin index publishes on the family's aligned version 0.4.16. This is the largest change since v0.4.15: the index gains six new entries, retires 52 existing entries under a host-floor rule, and re-admits one plugin under a new floor, taking the catalog from 151 entries to 106. The package name, the index data structure, the install path and the wire protocol are unchanged.

> **Compatibility**: there are no breaking changes in this release. `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer stay at `>=0.2.2-rc.1`, and `package.json` changes nowhere except `version` this round. Every other frozen identifier is unchanged: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry, with the same `files` list and the same `exports` entry points); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. The entry shape gains and loses no fields. The one thing worth noting is the catalog shrinking from 151 entries to 106: retirement acts on the store catalog only, and this repository carries links and metadata while never vendoring plugin code, so removing an entry touches no installed plugin.

### New Features

- Register the desktop notification plugin `dsh-plugin-desktop-notify`: a desktop banner on every finished turn, on a pending approval, answer or plan confirmation, and on a failed turn, with an unread badge on the app icon counting the sessions that need attention and a click that jumps to that session; copy follows the DSH interface language, subagent sessions stay quiet by default, title and body lengths are configurable, and the host additionally opens an HTTP endpoint on the loopback address for scripts and other tools to post notifications
- Register plugin auto update `dsh-plugin-auto-update`: a per-package allowlist drives an npm lookup of the latest version for installed plugins, only ticked packages are updated, local link and file installs plus pinned versions and failing packages are skipped, and neither a major bump nor a prerelease happens by default; updates go through the running official plugin manager in the profile, so the profile write lock, pnpm execution, bundle patch validation and hot reload stay the host's responsibility, a failed install puts the previous version back, and each round appends its result to a JSON log
- Register the study companion `dsh-tutorloop`: small-step practice over self-chosen material with evidence feedback and Leitner spaced review, 18 teacher tools behind a bilingual student panel, reusing the current DSH session model so no second model key is needed; study records stay local per workspace while chosen material and answers can be sent to the host model, and six hand-written sample questions ship built in with the real question bank imported by the user. The entry declares DSH `>=0.2.1-rc.2 <0.3.0-0` and Python 3.11+
- Register `dsh-character-cards`: bind a switchable character card to each session, injecting identity, tone, code style and hard constraints per session, with a default card, per-session override, a visual editor and single-file import and export
- Register the desktop power menu `dsh-power-menu-mac`: a top-right power button offering quit DSH and restart DSH, where a restart pulls the window back and confirms the new process actually registered with the window server; the endpoint is registered on the host's own web server and answers only on the loopback address, and enabling it injects a global hint into the session explaining those buttons. macOS only
- Register web search `dsh-keenable`: connect the host's built-in `web_search` and `web_fetch` to Keenable without adding any tool, so any model including a local one can reach the web; `web_search` returns ranked results with page excerpts and known publication dates, and `web_fetch` fetches server-side and returns markdown while refusing localhost and private addresses. Installing pins the host's `searchProvider` and `fetchProvider` to keenable and uninstalling restores the host defaults; key-free calls are limited per egress IP to 10 per second and 1000 per hour, the optional `KEENABLE_API_KEY` environment variable lifts the limit, and search terms and fetched URLs are sent to Keenable
- Re-admit `dsh-llm-verifier`: the entry was removed together with the rest of the retirement batch, then upstream 0.19.0 narrowed `engines.dsh` and all eight DSH peers to `>=0.2.0-rc.1 <0.3.0-0`, and with both the registry latest and 0.19.0 metadata read back at that range the entry was appended to the tail of the array through the ordinary registration path, with no rule exception opened for it; its four tools, auto-acceptance and Web settings page descriptions were re-checked against the upstream manifest, tests and source
