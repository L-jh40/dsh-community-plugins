社区插件索引随 dsh-web 家族对齐到统一版本 0.4.12。本版本收录五条社区插件条目，索引条目总数从 143 增至 148；索引数据源、包名、安装方式与 DSH 版本门槛均保持不变。

> **兼容性**：本版本没有破坏性变更。冻结标识全部保持原样——包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（仍按同一包名从 registry 安装，包内 `files` 清单与 `exports` 入口不变）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。宿主下限保持 `dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 的 `>=0.2.1-rc.3`，既未收紧也未放宽，停在 rc.3 及以上的宿主都能直接安装。

### 新功能

- 收录技能安装 `dsh-skill-install`：从 GitHub 仓库搜索并安装 `SKILL.md` 技能，可装到全局、当前项目或自定义目录，与内置 `skill-filesystem` 联动，装完即时生效。安装会把第三方仓库的 `SKILL.md` 原样写入技能根目录，只应安装信任的仓库
- 收录删除已归档对话 `dsh-delete-archived`：为已归档会话在侧边栏增加「删除对话」入口，另有模型可调用的 `delete_archived_conversation` 工具。侧边栏走两步确认，而工具调用没有二次确认且删除不可恢复；与 `dsh-archived-chats` 的区别是清单与删除能力的增量只有这两个入口，与 `dsh-delete-session` 的区别是只处理已归档会话
- 收录断点续跑按钮 `client-resume-button`：在输入框加一个「继续」按钮，上一轮被中止、崩溃或报错结束后，输入框为空时按钮出现，点一下发出续跑提示，让模型接着把那一轮做完。按钮位于模型选择器左侧，开始输入或添加附件时收窄隐藏，清空后展开回来。它不恢复中断时的半截输出——那部分内容从未落盘，插件是新开一轮重做
- 收录 DSH 版本守卫 `dsh-version-guard`：记录插件版本与 profile 配置快照，插件冲突导致 DSH 无法启动时，通过独立恢复页回退到已知可用配置。支持单插件停用、恢复启用、版本锁定与显式依赖同步，不回退 DSH 应用本身
- 收录 MiniMax Code 模型接入 `dsh-connect-minimaxcode`：把本机 MiniMax Code 桌面 App（国内版）的模型接入 DSH，零配置、无需 API Key，也可在插件页面发起 OAuth 设备码登录。上游是标准 Anthropic Messages 协议，复用 DSH 自带的 provider，工具调用、推理块与上下文压缩由 DSH 托管，模型目录从上游实时拉取。输入框工具行显示一枚余额胶囊（仅在选中本插件的模型时出现），插件页面另有余额卡片、本机消耗折算的等效金额、7 天内与 30 天内到期的积分批次以及每日签到。前置条件是本机已安装并登录该桌面 App，否则模型列表只回落为两个内置占位条目、实际调不通；为续期已过期的桌面 App 登录态，插件会按该 App 自己的格式原子写回其 auth 文件，用插件自己登录时凭据只写插件自己的 `~/.dsh/.minimaxcode-auth.json`。非官方插件，依赖 MiniMax 客户端的非公开接口，客户端更新后可能失效

### 其他改动

- 版本从 0.4.11 对齐到 0.4.12：本包是单包仓库，`package.json` 的 `version` 是唯一的版本声明点（`git grep` 全仓确认无第二处声明）；`dsh.engines.dsh`、`@deepseek-ai/dsh` peer、SDK devDependency 与 lockfile 均未移动

The community plugin index publishes on the family's aligned version 0.4.12. This release registers five community plugin entries, growing the index from 143 to 148 entries; the data source, the package name, the install path and the DSH version floor are unchanged.

> **Compatibility**: there are no breaking changes in this release. Every frozen identifier is unchanged: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry, with the same `files` list and the same `exports` entry points); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. The host floor stays at `>=0.2.1-rc.3` in `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer: it is neither tightened nor relaxed, so any host on rc.3 or later installs this release directly.

### New Features

- Register Skill Install `dsh-skill-install`: searches GitHub repositories and installs their `SKILL.md` skills into the global, project, or a custom directory, hot-loading through the built-in `skill-filesystem`. Installation copies a third-party repository's `SKILL.md` verbatim into a skills root, so only trusted repositories should be installed
- Register Delete Archived Conversations `dsh-delete-archived`: adds a sidebar delete entry for archived conversations plus the model-callable `delete_archived_conversation` tool. The sidebar asks for a two-step confirm, while the tool call has none and deletion is irreversible; unlike `dsh-archived-chats` the increment is only those two entry points, and unlike `dsh-delete-session` it only touches archived sessions
- Register Resume Button `client-resume-button`: adds a Continue button to the composer. After a turn ends aborted, interrupted or errored, the button appears while the composer is empty, and one click sends a continuation notice so the model picks that turn back up. It sits left of the model selector and collapses while you type or attach a file. It does not restore the interrupted output - that partial content was never persisted, so the plugin starts a new turn instead
- Register DSH Version Guard `dsh-version-guard`: snapshots plugin versions and profile configuration, and an independent recovery page restores a known-good configuration when plugin conflicts prevent DSH from starting. Supports disabling and re-enabling plugins, version pinning, and explicit dependency synchronization; it does not roll back the DSH application
- Register MiniMax Code Model Connect `dsh-connect-minimaxcode`: brings the models of the MiniMax Code desktop app (China region) into DSH, zero configuration and no API key, with an OAuth device-code sign-in offered on the plugin page as an alternative. The upstream speaks the standard Anthropic Messages protocol, so DSH's own provider is reused and tool calls, reasoning blocks and context compaction stay Harness-owned, while the model catalog is pulled live. A balance pill sits in the composer tool row, drawn only while this plugin's models are selected, and the plugin page adds a balance card, this machine's consumption converted to an equivalent cost, the credit batches expiring within 7 and 30 days, and the daily check-in. The prerequisite is the desktop app installed and signed in on this machine, without which the model list falls back to two built-in placeholders that cannot actually be called; to renew an expired desktop-app sign-in the plugin writes the app's auth file back atomically in the app's own format, and a sign-in made through the plugin itself stores its credential only in the plugin's own `~/.dsh/.minimaxcode-auth.json`. Unofficial plugin: it depends on the MiniMax client's non-public interfaces, which a client update may break

### Other Changes

- The version moves from 0.4.11 to 0.4.12: this is a single-package repository, so `version` in `package.json` is the only place the version is declared (a repository-wide `git grep` confirms there is no second declaration point); `dsh.engines.dsh`, the `@deepseek-ai/dsh` peer, the SDK devDependencies and the lockfile do not move
- The index only appends: across `v0.4.11..v0.4.12` the `community.json` change is 57 added lines and 0 removed, with the five entries sitting at the tail and no existing entry modified or deleted
- Agent Notes: record the 2026-10-28 registration round, where #47, #46, #41 and #36 merged out of twenty-four open registrations, accounting for the five entries added here (#41 brought two at once); #43, #40 and #27 returned with their exact remaining items, and the fourteen never-reviewed registrations are deferred to the next round. Two of the four merges stated their entry copy accurately before landing: #41 repaired the broken JSON and moved the destructive-tool warning and the `dsh-delete-session` comparison into the entry, and #46 wrote the desktop-app prerequisite, the atomic credential write-back and the narrowed engine range into the entry
- This package builds no client bundle: `src/` is unchanged since v0.4.9 and never references the package version, and `lib/` is not committed (it is in `.gitignore`) but produced by `pnpm build` in the release pipeline
