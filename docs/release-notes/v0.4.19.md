社区插件索引随 dsh-web 家族对齐到统一版本 0.4.19。与 `v0.4.18` 不同，本版带用户可见变更：`v0.4.18` 之后本仓合入 22 笔提交，`community.json` 由 124 条增至 137 条（13 条新收录 + 3 条既有条目修订），并首次为插件页提供显示元数据——列表里这一行的标题与灰色描述不再回退到 npm 包名与英文清单描述。

> **兼容性**：宿主下限未动，`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 仍是 `>=0.2.2-rc.2`，与 0.4.18 一致。除目录里新增 13 条外没有破坏性变更：包名 `@linxin666/dsh-client-ui-community-plugins`；安装方式（同一包名从 registry 安装）；持久化标识（`community.json` 的文件名、条目结构与字段名，profile 里已持久化的 `ui-community-plugins` 挂载行与相关键名）；线协议（bundle patch 里那行惰性 `ui-community-plugins` 行，以及插件对宿主暴露的字段）均未改名或改形。`exports` 与 `files` 只有新增：`./locale/en.json`、`./locale/zh.json` 两个子路径与 `locale/` 目录，原有三个入口及其指向未变。目录中少数条目的宿主兼容区间由各自上游决定（例如 `dsh-archived-chats` 声明的 `0.2.2-rc.3`），商店文案逐条写明，不改变本包自身的安装前提。

### 新功能

**13 条新收录的社区插件**（按 `id` 升序插入，条目结构与字段名不变）：

- `dsh-agent-lines`「角色线」（`tools`/`dev`）：把线当岗位——稳定角色身份 + 可替换 Session、持久消息、结构化交接、退役/休眠与只读看板，不预设固定流程或 DAG
- `dsh-asl-workspace`「ASL 技能工作区」（`ui`/`panel`）：把 ASL Mode 与 Skill 呈现为可编辑 Mermaid 画板，带完整文件树与 Markdown 编辑；该条无 `npm` 字段（registry 查无此包），商店按仓库地址安装，未配置 ASL Harness 路径时可安全挂载并给出指引
- `dsh-better-classifier`「BetterClassifier 会话分类」（`ui`/`panel`）：用嵌套虚拟文件夹、彩色标签与树形搜索整理侧栏项目与会话，不改真实工作目录；正文检索走 DSH 本地共享索引
- `dsh-jump`「跳跃导航」（`ui`/`panel`）：Vimium 式字母标签，覆在界面里每个可见的可交互目标上，点击与聚焦两组组合键，聚焦模式默认关闭
- `dsh-liquid-glass`「液态玻璃」（`ui`/`render`）：官方风格折叠设置、通透界面与本地图片或视频背景
- `dsh-man-031`「Man！花了这么多钱！」（`utility`/`notify`）：每轮结束离线播报本轮费用或 Token 用量，费用优先取 `dsh-cost-meter`；随包人物图、图标与预制语音不随 MIT 再分发，仅限随插件个人非商业使用
- `dsh-multithread-downloader`「多线程下载器」（`utility`/`net`）：HTTP Range 分片并发下载，带侧边栏面板、对话进度条、断点续传、镜像回退、SHA-256 校验、限速与 Agent 工具
- `dsh-runninghub-plugin`「RunningHub 工作流」（`integration`/`external-ai`）：`runninghub_search` 与 `runninghub_call` 两个模型工具运行已保存的 ComfyUI 工作流，API Key 按国内站与海外站分池轮换；需自备 Key，运行工作流消耗 RH 币
- `dsh-sidebar-suite`「侧栏布局套件」（`ui`/`panel`）：把侧栏的工作区与会话两组排成标签页或浮层、也可切回官方默认，同时管理临时会话（退出删除或每日定时清理），9 项配置在详情页都有图形开关
- `dsh-skills-tools`「Skills 管理器」（`tools`/`dev`）：从 Git 仓库导入 Agent Skills、按仓库分组、逐项启停、展开看 SKILL.md，仓库以只读快照保存
- `dsh-triage`「分诊台」（`tools`/`dev`）：装前判断与装后归因，默认只读——不安装到 profile、不卸载、不判安全；只有显式 `--apply` 才改配置，先备份、`--undo` 可逐字节还原
- `session-chains`「交接鏈」（`tools`/`context`）：把互相交接的会话聚成一条链，带场次编号、就地改名、搜索与拖拽归链、置顶封存；自动交接、语音播报、工作区收合三项默认关闭，自动编号会改写既有标题且卸载不自动还原
- `smart-compaction`「智能压缩」（`tools`/`context`）：`compact_now` 基于公开的 `compactRegion()` 接口且回合中途可用，`context_status` 报告真实 token 用量；待办标记完成且越过 `safePointRatio`（默认 0.5）时自动压缩，自带的 80% 阈值仍作兜底

**插件页显示元数据**（`da6b775`）：官方插件列表渲染每行的标题与灰色描述时，读包内 `locale/<lang>.json` 的 `meta.title` 与 `meta.description`，并经本包自己的 `exports` 映射解析每个文件。此前本包没有这条通道，插件页只能回退到 npm 包名与英文 `package.json` 描述。本版新增 `locale/en.json`（`Community plugins` / `Browse community plugins and install them in one click.`）与 `locale/zh.json`（`社区插件` / `浏览社区插件与一键安装`），补齐对应的两个 `exports` 键，并把 `locale` 目录写进 npm 的 `files` 白名单；`icon` 字段（`icon.svg`）在 0.4.18 已存在，本版把它的存在、路径与扩展名一并纳入新测试的门禁。

### 其他改动

- 3 条既有条目修订：`dsh-archived-chats`（`4d3e665`）把 `author` 由账号改名前的 `Ultronen` 改为 `Ultroncn`，并把中英描述里的宿主兼容声明由「最低 0.2.2-rc.1」改为 `>=0.1.0-rc.7 || 0.2.2-rc.1 || 0.2.2-rc.2 || 0.2.2-rc.3`，旧宿主无需先升级 Harness 即可升级插件；`dsh-plugin-restart-button`（`865d1d1`）补上 `npm` 字段 `dsh-plugin-restart-button`，商店可按 registry 直装；`dsh-thanks-carl`（`97eec8b`）描述对齐上游 `0.3.0`，改写为刺猬卡尔桌宠、12 种预生成 AI 动作、摸摸互动、25/45 分钟专注、快捷菜单与可选边缘闲逛
- 分类修正（`0d6703f`）：`dsh-agent-lines` 由 `agent`/`preset` 归入 `tools`/`dev`，它是跨会话开发工作流工具而非预设，商店布局里 `agent` 二级分类只允许 `preset`
- 新增 `tests/display-metadata.spec.ts`（92 行、5 个用例，`da6b775`）把上述显示元数据做成门禁：两个语言文件必须存在；`exports` 里的 `./locale/*` 键与磁盘上的实际文件一一对应；每份文件只带非空的 `meta.title` 与 `meta.description`；中文标题与描述必须与英文不同，且中文描述不超过 20 个汉字；`files` 必须同时包含 `locale` 与 `icon` 指向的文件
- `CONTRIBUTING.md` 新增「Retirement and re-listing」（`bb6d9fa`）：写明退役条目的快照、提交历史与裁定记录存放位置，维护者不会用机器人向第三方仓库群发通知或批量点名作者，并给出上游抬高低限后按「Adding or updating a plugin entry」自助重新上架的路径
- `.agents/notes` 记下两轮登记：2026-11-13 轮（`be0bd55`）11 个 PR 合入、索引 124 增至 132；2026-11-15 轮（`f388dff`）6 个 PR 合入、索引 132 增至 137，其中 `dsh-better-classifier` 的 `engines.dsh` 为精确版本 `0.2.2-rc.2`、`dsh-liquid-glass` 包内缺 `engines.dsh`，两者都按知情选择与非阻塞跟进项记录而非退回；2026-11-05 退役轮记录随 `bb6d9fa` 补入「不群发机器人通知」这一被否决方案的理由
- 版本从 `0.4.18` 推进到 `0.4.19`：本仓是单包仓库，`package.json` 的 `version` 是唯一的版本声明点；`lib/` 不入库（在 `.gitignore` 中）由发布流水线的 `pnpm build` 生成，本轮 `src/`、`scripts/`、`cordis.patch.yml` 与 devDependencies 没有任何改动

### 升级提示

- 宿主下限与 0.4.18 相同，仍是 `>=0.2.2-rc.2`：`dsh.engines.dsh` 与 `@deepseek-ai/dsh` peer 未变，已在跑 0.4.18 的宿主升级本包无需先动宿主
- `npm i @linxin666/dsh-client-ui-community-plugins@0.4.19` 即拿到含 137 条的 `community.json` 与 `locale/` 目录；线上 Workshop 商店与 dsh-market.com 的 manifest 还须在 `dsh-web` 移动 `satellites/dsh-community-plugins` 的 submodule 钉版并重建 `market/dist` 后才会显示这 13 条新增
- 插件页标题与描述取自 `locale/`，语言文件缺失、`exports` 键对不上或 npm 丢了 `locale` 目录都会让整条元数据读取失败并回退到包名与英文描述；`tests/display-metadata.spec.ts` 已把这三条前提锁进 CI

The community plugin index publishes on the family's aligned version 0.4.19. Unlike `v0.4.18`, this release carries user-visible change: 22 commits landed after `v0.4.18`, `community.json` grows from 124 to 137 entries (13 new registrations plus 3 revisions of existing entries), and the plugin page gets display metadata for the first time — the row title and grey description no longer fall back to the npm package name and the English manifest description.

> **Compatibility**: the host floor is untouched, `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer staying at `>=0.2.2-rc.2` as in 0.4.18. Beyond the 13 new catalog entries there are no breaking changes: the package name `@linxin666/dsh-client-ui-community-plugins`; the install path (the same package name from the registry); the persistence identifiers (`community.json`'s filename, entry shape and field names, plus the already-persisted `ui-community-plugins` mount row and the related profile keys); and the wire protocol (the inert `ui-community-plugins` row of the bundle patch and the fields the plugin exposes to the host) are neither renamed nor reshaped. `exports` and `files` only gain entries: the `./locale/en.json` and `./locale/zh.json` subpaths and the `locale/` directory, while the three existing entry points keep their targets. The host compatibility ranges a few catalog entries state come from their own upstreams (for example the `0.2.2-rc.3` range `dsh-archived-chats` declares), are spelled out in each store description, and do not change this package's own install requirement.

### New Features

**13 newly registered community plugins** (inserted in ascending `id` order, with the entry shape and field names unchanged):

- `dsh-agent-lines` (tools/dev): models role lines as positions — a stable role identity with a replaceable session, durable messages, structured handoffs, retire/hibernate and a read-only board, with no fixed workflow or DAG assumed
- `dsh-asl-workspace` (ui/panel): renders ASL Modes and Skills as editable Mermaid boards with a full file tree and Markdown editing; the entry carries no `npm` field (the package is not on the registry), so the store installs it from the repository, and it mounts safely with configuration guidance before an ASL Harness path is set
- `dsh-better-classifier` (ui/panel): organizes sidebar projects and conversations with nested virtual folders, colored tags and tree-shaped search without touching real working directories, and uses DSH's local shared index for content search
- `dsh-jump` (ui/panel): Vimium-style letter labels over every visible interactive target, with separate click and focus chords, and focus mode off by default
- `dsh-liquid-glass` (ui/render): official-style collapsible settings, translucent surfaces and local image or video backgrounds
- `dsh-man-031` (utility/notify): reports per-turn cost or token usage with bundled offline audio, preferring `dsh-cost-meter` for cost; the bundled portrait, icons and pre-made voice clips are not redistributed under the MIT grant and are for personal, non-commercial use with this plugin only
- `dsh-multithread-downloader` (utility/net): parallel HTTP Range downloads with a sidebar panel, composer progress strip, resume, mirror fallback, SHA-256 checks, rate limiting and an agent tool
- `dsh-runninghub-plugin` (integration/external-ai): the `runninghub_search` and `runninghub_call` model tools drive ComfyUI workflows saved on RunningHub, with API keys pooled separately for the China and international sites; it needs your own key, and running a workflow spends RH coins
- `dsh-sidebar-suite` (ui/panel): arranges the sidebar's workspaces and sessions groups as tabs or an overlay, switches back to an unchanged official default, and manages temporary sessions (deleted on quit or swept daily); all nine config keys have graphical switches
- `dsh-skills-tools` (tools/dev): imports Agent Skills from Git repositories, groups them by repository, toggles each one and expands SKILL.md, keeping repositories as read-only snapshots
- `dsh-triage` (tools/dev): pre-install judgement and post-install attribution, read-only by default — it never installs into your profile, never removes and never claims safety; only an explicit `--apply` changes config, after a backup, and `--undo` restores the bytes
- `session-chains` (tools/context): groups sessions that hand off to each other into one chain, with per-session numbering, in-place renames, search and drag-to-rechain, pinning and archiving; auto-handoff, voice announcements and workspace folding are off by default, and numbering rewrites existing titles without being reverted by uninstalling
- `smart-compaction` (tools/context): `compact_now` builds on the public `compactRegion()` API and works mid-turn, `context_status` reports real token usage, and compaction triggers automatically once a todo is completed and usage passes `safePointRatio` (0.5 by default), with the built-in 80% threshold kept as the backstop

**Plugin page display metadata** (`da6b775`): the official plugin list renders each row's title and grey description from `meta.title` and `meta.description` in the package's own `locale/<lang>.json`, resolving each file through that package's `exports` map. This package had no such channel, so the page fell back to the npm package name and the English `package.json` description. The release adds `locale/en.json` (`Community plugins` / `Browse community plugins and install them in one click.`) and `locale/zh.json` (`社区插件` / `浏览社区插件与一键安装`), the two matching `exports` keys, and the `locale` directory in npm's `files` whitelist; the `icon` field (`icon.svg`) already existed in 0.4.18, and this release folds its presence, path and extension into the new test gate.

### Other Changes

- Three revisions of existing entries: `dsh-archived-chats` (`4d3e665`) moves `author` from the pre-rename `Ultronen` to `Ultroncn` and rewrites the host compatibility claim in both descriptions from "requires 0.2.2-rc.1 or later" to `>=0.1.0-rc.7 || 0.2.2-rc.1 || 0.2.2-rc.2 || 0.2.2-rc.3`, so older hosts can upgrade the plugin without upgrading Harness first; `dsh-plugin-restart-button` (`865d1d1`) gains the `npm` field `dsh-plugin-restart-button`, letting the store install it from the registry; `dsh-thanks-carl` (`97eec8b`) aligns its description with upstream `0.3.0`, describing the Carl hedgehog companion, 12 pre-generated AI sprite actions, pat reactions, a 25/45-minute focus timer, a quick menu and optional edge wandering
- Category fix (`0d6703f`): `dsh-agent-lines` moves from `agent`/`preset` to `tools`/`dev`, since it is a cross-session development workflow tool rather than a preset, and the store layout allows `preset` as the only `agent` subcategory
- A new `tests/display-metadata.spec.ts` (92 lines, 5 cases, `da6b775`) gates that display metadata: both language files must exist; the `./locale/*` keys in `exports` and the files on disk must match one for one; each file carries only a non-empty `meta.title` and `meta.description`; the Chinese title and description must differ from the English ones and the Chinese description must stay within 20 Han characters; and `files` must contain both `locale` and the file `icon` points at
- `CONTRIBUTING.md` gains a "Retirement and re-listing" section (`bb6d9fa`): it records where retired entries' snapshots, commit history and rationale live, states that maintainers do not run bots to open notification issues across third-party repositories or to name every author in bulk, and points a plugin whose upstream raises its floor back to the catalog through "Adding or updating a plugin entry"
- `.agents/notes` records two registration rounds: 2026-11-13 (`be0bd55`) merged 11 PRs and moved the catalog from 124 to 132; 2026-11-15 (`f388dff`) merged 6 PRs and moved it from 132 to 137, noting `dsh-better-classifier`'s exact `engines.dsh` of `0.2.2-rc.2` and `dsh-liquid-glass`'s missing `engines.dsh` as informed choices and non-blocking follow-ups rather than rejections; the 2026-11-05 retirement record gains, with `bb6d9fa`, the rationale for rejecting mass bot notification
- The version advances from `0.4.18` to `0.4.19`: this is a single-package repository, so `version` in `package.json` is the only declaration point; `lib/` is not committed (it is in `.gitignore`) and is produced by the release pipeline's `pnpm build`, while `src/`, `scripts/`, `cordis.patch.yml` and the devDependencies are untouched this round

### Upgrade Note

- The host floor is the same as 0.4.18, `>=0.2.2-rc.2`: `dsh.engines.dsh` and the `@deepseek-ai/dsh` peer are unchanged, so a host already on 0.4.18 upgrades this package without touching the host
- `npm i @linxin666/dsh-client-ui-community-plugins@0.4.19` delivers the 137-entry `community.json` and the `locale/` directory; the live Workshop store and the dsh-market.com manifest update only after `dsh-web` moves its `satellites/dsh-community-plugins` submodule pin and rebuilds `market/dist`
- The plugin page reads its title and description from `locale/`; a missing language file, an `exports` key without its file, or an npm publish that drops the `locale` directory makes the whole metadata read fail and falls back to the package name and English description, and `tests/display-metadata.spec.ts` now locks all three preconditions into CI
